# 3D Character Avatar Model Directory

Place your `.glb` character model file inside this directory (`src/three/3d_avatar/avatar.glb` or any `*.glb` filename).

The portfolio automatically detects any `.glb` file in `src/three/3d_avatar`, syncs it to `public/models/3d_avatar.glb`, and renders it in the Hero section with full-body standing framing, floor contact shadow, embedded skeletal animation playback, and mouse parallax tilt.
